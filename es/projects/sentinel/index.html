Monitor de seguridad de Windows

SENTINEL explora la monitorización defensiva de una máquina Windows: análisis locales, comprobaciones de procesos y una terminal interactiva para inspeccionar resultados.

El proyecto es experimental: documenta su alcance y sus límites en lugar de prometer una protección de tipo antivirus certificado.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Acceso interactivo por línea de comandos a las funciones de análisis y monitorización.
  • Comprobaciones en segundo plano de procesos, arranque, archivos y cambios de red.
  • Una auditoría de sistema agrupada que reúne varios controles locales.
  • Código fuente que muestra la implementación y sus fronteras específicas de Windows.

Entorno y requisitos

Un entorno Windows compatible. El repositorio usa API nativas de Windows y utilidades del sistema; no es una aplicación de navegador ni un mod de Minecraft multiplataforma.

Primeros pasos

Empieza por el README e inspecciona el código y los comandos antes de ejecutar la herramienta. Usa un entorno de pruebas aislado, comprende los permisos implicados y revisa un hallazgo antes de actuar sobre un archivo o un proceso.

Alcance, límites y atribución

La detección es heurística y puede producir falsos positivos o pasar amenazas por alto. Este portfolio no reivindica certificación de seguridad independiente, detección garantizada ni sustitución de un producto de seguridad mantenido. Este sitio web no realiza análisis.
