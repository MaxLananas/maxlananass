HomeGUI — project file_□×

Mod de Minecraft del lado del cliente

HomeGUI es mi mod cliente de gestión de homes de Minecraft. En lugar de escribir repetidamente un nombre de home en el chat, abre una interfaz, busca los destinos disponibles y selecciona adónde teletransportarte.

El mod lee la respuesta del servidor a /homes y presenta esa información en el cliente. No instala un nuevo sistema de teletransporte en el servidor: la diferencia entre interfaz cómoda y plugin de servidor sigue siendo esencial para decidir si encaja en tu setup.

HomeGUI — interfaz

Qué hace el proyecto

  • Abrir la interfaz con la tecla H por defecto; cambia el atajo en los controles de Minecraft.
  • Buscar nombres de homes y marcar favoritos con clic derecho.
  • Consultar el historial reciente de teletransporte y estadísticas de uso local.
  • Usar la interfaz en inglés o francés; las preferencias se guardan en config/homegui.json.

Entorno y requisitos

Un servidor Fabric Loader y Fabric API compatibles, además de un servidor que use comandos de homes cuya respuesta a /homes pueda analizarse. El mod es del lado del cliente; los permisos del servidor siguen aplicándose.

Primeros pasos

Instala un Fabric Loader y una Fabric API compatibles y coloca el JAR de HomeGUI en tu carpeta de mods. Únete a un servidor con comandos de homes compatibles antes de abrir la interfaz. El archivo JSON local se genera en el primer arranque.

Alcance, límites y atribución

Los permisos y las reglas de teletransporte del servidor siguen aplicándose. Un servidor con formato de chat muy personalizado u ofuscado puede no analizarse correctamente. Comprueba la página de descarga actual para conocer las versiones soportadas.
