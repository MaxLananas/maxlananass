PineappleUI — project file_□×

Experimento de transpilador de interfaces

PineappleUI es mi experimento para describir interfaces de escritorio con layouts tipo HTML/CSS y generar código Java Swing nativo. Conecta un vocabulario de interfaz familiar del web con un objetivo de UI de escritorio.

El objetivo documentado actual es Swing. La fuente describe soporte de componentes comunes, contenedores, layout, estilo e integración de eventos. La pregunta útil no es si una página web puede convertirse en cualquier aplicación, sino qué partes de una descripción de interfaz se mapean con claridad al objetivo soportado.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Describir una interfaz en un archivo .pineui.
  • Generar código Java Swing desde la descripción de interfaz soportada.
  • Usar el comando de compilación/ejecución documentado para explorar el resultado.
  • Mantener visible el comportamiento específico del objetivo en lugar de suponer que toda función HTML o CSS es portable.

Entorno y requisitos

Python para el transpilador y un entorno Java adecuado para compilar o ejecutar el código Swing generado. El objetivo documentado actual es Swing.

Primeros pasos

El comando de inicio del README es python main.py myui.pineui --compile --run. Empieza con un layout pequeño e inspecciona el Java generado antes de ampliar. Es un flujo de desarrollo, no una instalación de mod de Minecraft: el archivo de entrada pertenece al transpilador.

Alcance, límites y atribución

JavaFX, Android XML y otros frameworks de UI figuran como objetivos futuros, no como funciones actuales reivindicadas aquí. Trátalo como experimental, verifica la sintaxis soportada en el repositorio y prueba el código generado antes de depender de él.
