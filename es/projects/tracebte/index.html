Plugin tutorial para Paper

TraceBTE es un plugin tutorial de trazado interactivo desarrollado para BuildTheEarth France. Ayuda a introducir la secuencia entre encontrar un lugar real y colocar su planta de edificio en Minecraft.

El tutorial vive en el servidor, no en un cliente Fabric. Su tema es el método del builder: obtener coordenadas geográficas, llegar al lugar correspondiente en el mundo proyectado, colocar marcadores de esquina y usar WorldEdit para conectar y prolongar la construcción.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Iniciar la secuencia guiada con /tuto e interrumpirla con /tuto stop.
  • Obtener coordenadas GPS y usar el comando /tpll del servidor.
  • Colocar las esquinas del edificio y trazar los bordes de la planta con WorldEdit //line.
  • Introducir selecciones y //stack para prolongar la planta hacia arriba.

Entorno y requisitos

Un servidor Paper compatible, Java 21+ y FastAsyncWorldEdit según los requisitos documentados. El README no pide un archivo de configuración separado para el tutorial.

Primeros pasos

La instalación documentada coloca el JAR del plugin en la carpeta plugins del servidor Paper, seguida de un reinicio. Comprueba primero las versiones requeridas de Java y FAWE. El README no exige un archivo de configuración separado para el tutorial.

Alcance, límites y atribución

Es un tutorial, no un importador automático de edificios ni una alternativa a configurar un servidor BTE. Sus comandos y ejemplos asumen que las herramientas de servidor esperadas están disponibles. Este portfolio no es un sitio de soporte oficial de BuildTheEarth.
