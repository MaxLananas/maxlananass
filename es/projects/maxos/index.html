MaxOS — project file_□×

Experimento de sistema operativo asistido por IA

MaxOS es un proyecto bare-metal x86 experimental. Explora una pequeña ruta de arranque y un entorno de kernel, en lugar de presentar un reemplazo generalista de un sistema operativo existente.

El README describe explícitamente un desarrollo asistido por IA y reporta arranque x86 y salida de texto VGA 80×25, con interrupciones, temporización y trabajo de memoria aún listados como áreas en desarrollo. Esa frontera forma parte del proyecto.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Código de arranque en Assembly y componentes de kernel en C/Assembly.
  • Una imagen y un flujo QEMU documentados para un entorno emulado.
  • Salida de texto VGA como hito pequeño y observable.
  • Herramientas de desarrollo en Python junto a las fuentes de bajo nivel.

Entorno y requisitos

Un entorno de desarrollo tipo Unix o Linux con las cadenas de herramientas de compilación cruzada esperadas; los comandos Make y QEMU documentados deben estar disponibles. El repositorio está pensado para un entorno emulado.

Primeros pasos

Lee el Makefile y el README y usa un emulador para tus experimentos. Inspecciona las fuentes de arranque y kernel junto a la salida observada. Mantén este trabajo separado de una máquina de producción.

Alcance, límites y atribución

El proyecto no pretende ser un sistema operativo de uso diario, con compatibilidad amplia de hardware ni seguridad de nivel producción. Las zonas descritas como en curso siguen siendo trabajo pendiente, no funciones entregadas.
