BuildersUtilities — BT Corsica — project file_□×

Plugin de Paper adaptado / fork

Este repositorio es mi adaptación BT Corsica de BuildersUtilities, no un plugin original escrito íntegramente por mí. La cadena original importa: se basa en BuildersUtilities de TehBrian, que a su vez se apoya en Builder’s Utilities de Arcaniax.

La adaptación combina trabajo de compatibilidad para las versiones documentadas de Paper y Java con ayudas de construcción adecuadas al flujo del equipo. El repositorio describe la migración desde API eliminadas junto a añadidos como waypoints y comandos de tiempo y clima.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Abrir el menú de habilidades con /bu e inspeccionar comandos con /bu help.
  • Gestionar waypoints con /wp add, /wp tp, /wp list y /wp remove.
  • Usar comandos de tiempo de construcción y de clima cuando los permisos lo permiten.
  • Acceder a herramientas de objetos especiales, color de armadura y estandartes expuestas por el plugin.

Entorno y requisitos

El README documentado apunta a Paper 1.21.10 y Java 21. Los permisos del servidor gobiernan los comandos expuestos; un build Gradle genera los JAR en build/libs.

Primeros pasos

Revisa la lista de permisos del plugin.yml y los requisitos de build actuales antes de instalar la adaptación en un servidor Paper. El README documenta un build Gradle con Java 21 y JAR generados en build/libs. Prueba configuración y permisos en un servidor no productivo.

Alcance, límites y atribución

Los autores originales conservan sus respectivos créditos. Esta página no rebautiza el proyecto como plugin oficial de BuildTheEarth ni afirma una licencia a partir del solo README: consulta el LICENSE del repositorio y los requisitos originales antes de redistribuir.
