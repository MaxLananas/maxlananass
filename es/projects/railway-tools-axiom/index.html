Addon de Axiom

Railway Tools for Axiom es mi addon para planificar vías ferroviarias en flujos de BuildTheEarth. El builder coloca puntos de control, inspecciona la ruta propuesta y confirma la colocación de bloques desde la interfaz de herramientas de Axiom.

La ruta usa interpolación de splines Catmull–Rom para conectar los puntos de control con curvas. La implementación muestrea después la curva en posiciones de bloques y clasifica los segmentos rectos, diagonales y de giro para elegir los estados de bloque adecuados. Es una ayuda de construcción en un mundo proyectado, no un simulador de ingeniería ferroviaria.

Ver en Modrinth código fuente

Qué hace el proyecto

  • Colocar puntos de control con clic derecho y confirmar la ruta con Enter.
  • Eliminar el último punto con Supr o borrar la ruta con Escape.
  • Ajustar la densidad de muestreo de 2 a 32 puntos por bloque.
  • Previsualizar la colocación antes de aplicarla, con seguimiento opcional del terreno.

Entorno y requisitos

Minecraft 1.21.10, Fabric Loader 0.16.0 o posterior, Fabric API y Axiom, con los permisos TOOL y BUILD_SECTION de Axiom. El addon no funciona sin Axiom.

Primeros pasos

Instala el entorno Fabric compatible y Axiom, y usa la herramienta BTE Rail Path en la paleta de Axiom. Empieza con un tramo corto para comprobar la paleta, la densidad de curvas y el ajuste al terreno antes de alargar un corredor. El README lista los permisos TOOL y BUILD_SECTION de Axiom.

Alcance, límites y atribución

Este addon no funciona sin Axiom. Las paletas de bloques y las API de Minecraft son sensibles a las versiones: usa los requisitos de la versión descargada. El proyecto no es una release oficial de Axiom ni de BuildTheEarth.
