Extensión Geyser

Los clientes Bedrock no muestran las altitudes extremas de mundos Java como BuildTheEarth. Hauteur desplaza la ventana vertical que ve el cliente Bedrock al subir.

Solo lado servidor: los Bedrock obtienen una franja vertical jugable del mundo Java.

Explorar en GitHub código fuente

Qué hace el proyecto

  • Remapea la ventana vertical al subir
  • Altitudes tipo BuildTheEarth
  • Sin mod cliente en Bedrock

Primeros pasos

Suelta la extensión junto a Geyser en el servidor.

Alcance, límites y atribución

Quedan aproximaciones de render Bedrock; consulta el repositorio.
