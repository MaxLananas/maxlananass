Minecraft building · Software development

I’m MaxLananas, a Minecraft builder and developer. This portfolio connects my build screenshots, BuildTheEarth-related contributions and the tools I develop for building, navigation and interface creation.

MaxLananas is the identity used by this portfolio and my GitHub profile. The accounts below link the projects, published work and contact route together.

Building and BuildTheEarth

The Minecraft screenshot gallery preserves each collaboration’s attribution. Work made within BuildTheEarth France is not presented as exclusively my creation. The BuildTheEarth section connects these images with my tools and unofficial community documentation.

Interfaces, mods and developer tools

My iProf redesign brings interface work into the portfolio through screenshots and a video. My Modrinth releases include Colorflow, Nostalgia Ultra Shader and Sculk Vision.

HomeGUI is a client interface for home commands; TraceBTE is a server-side tutorial; Railway Tools extends Axiom for path building. PineappleUI explores converting HTML/CSS-like interface descriptions into Java Swing code.

The project pages distinguish documented features from limitations and roadmap items. Forks retain the original authors’ credits.
