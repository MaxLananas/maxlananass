JukeBoxPlus — project file_□×

Minecraft music interface

JukeBoxPlus gives Minecraft’s music a visible interface. It exposes the track, artist or source and progress instead of leaving the player to guess which piece is playing.

The current Modrinth release describes a HUD and a full player for in-game music: discs, ambient tracks and dimension-specific categories. This is distinct from Now Playing IRL, which is concerned with music playing in external applications.

JukeBoxPlus — interface

What the project does

  • See the current track and playback progress in a HUD.
  • Browse and search the in-game music library.
  • Use play, pause, skip, shuffle, repeat and volume controls.
  • Open the player using its configurable key binding.

Environment and requirements

Download the release matching your Minecraft version and loader. Follow its listed dependencies and the rules of the server you use.

Getting started

Select the Fabric release for your Minecraft version on Modrinth, then follow its dependency instructions. Open the player to browse categories and adjust the HUD placement to suit your existing interface.

Scope, limitations and attribution

Descriptions in an older GitHub summary refer to external music, but the current Modrinth presentation describes Minecraft’s own music. This portfolio follows that release description and presents Now Playing IRL separately. It does not imply that Spotify music is included in the mod.
