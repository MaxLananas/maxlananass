Moniteur de sécurité Windows

SENTINEL explore la supervision défensive d’une machine Windows : analyses locales, vérifications de processus et un terminal interactif pour inspecter les résultats.

Le projet est expérimental : il documente son périmètre et ses limites plutôt que de promettre une protection de type antivirus certifié.

Explorer sur GitHub code source

Ce que fait le projet

  • Accès en ligne de commande interactif aux fonctions d’analyse et de supervision.
  • Vérifications en arrière-plan des processus, démarrages, fichiers et changements réseau.
  • Un audit système groupé qui réunit plusieurs contrôles locaux.
  • Code source montrant l’implémentation et ses frontières spécifiques à Windows.

Environnement et prérequis

Un environnement Windows compatible. Le dépôt utilise des API Windows natives et des utilitaires système ; ce n’est ni une application navigateur ni un mod Minecraft multiplateforme.

Premiers pas

Commencez par le README et inspectez le source et les commandes avant d’exécuter l’outil. Utilisez un environnement de test isolé, comprenez les permissions en jeu et revoyez un résultat avant d’agir sur un fichier ou un processus.

Périmètre, limites et attribution

La détection est heuristique et peut produire des faux positifs ou manquer des menaces. Ce portfolio ne revendique ni certification de sécurité indépendante, ni détection garantie, ni remplacement d’un produit de sécurité maintenu. Aucune analyse n’est effectuée par ce site web.
