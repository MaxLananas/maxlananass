BuildersUtilities — BT Corsica — project file_□×

Plugin Paper adapté / fork

Ce dépôt est mon adaptation BT Corsica de BuildersUtilities, pas un plugin original écrit entièrement par moi. La chaîne amont compte : il s’appuie sur BuildersUtilities de TehBrian, lui-même construit sur Builder’s Utilities d’Arcaniax.

L’adaptation combine un travail de compatibilité pour les versions documentées de Paper et de Java avec des aides de construction adaptées au workflow de l’équipe. Le dépôt décrit une migration hors d’API supprimées, aux côtés d’ajouts comme les waypoints et les commandes de temps/météo.

Explorer sur GitHub code source

Ce que fait le projet

  • Ouvrir le menu d’abilités avec /bu et inspecter les commandes avec /bu help.
  • Gérer les waypoints avec /wp add, /wp tp, /wp list et /wp remove.
  • Utiliser les commandes de temps de construction et de météo quand les permissions le permettent.
  • Accéder aux outils d’objets spéciaux, de couleur d’armure et de bannières exposés par le plugin.

Environnement et prérequis

Le README documenté vise Paper 1.21.10 et Java 21. Les permissions du serveur gouvernent les commandes exposées ; un build Gradle produit les JAR sous build/libs.

Premiers pas

Revoyez la liste de permissions du plugin.yml et les prérequis de build actuels avant d’installer l’adaptation sur un serveur Paper. Le README documente un build Gradle avec Java 21 et des JAR générés sous build/libs. Testez configuration et permissions sur un serveur hors production.

Périmètre, limites et attribution
