Addon Axiom

Railway Tools for Axiom est mon addon pour planifier des voies ferroviaires dans les méthodes BuildTheEarth. Le builder place des points de contrôle, inspecte le tracé proposé et confirme le placement des blocs depuis l’interface d’outils d’Axiom.

Le tracé relie les points de contrôle par interpolation de spline Catmull–Rom. L’implementation échantillonne ensuite la courbe en positions de blocs et classe les segments droits, diagonaux et tournants pour choisir les états de bloc adaptés. C’est une aide à la construction dans un monde projeté, pas un simulateur d’ingénierie ferroviaire.

Voir sur Modrinth code source

Ce que fait le projet

  • Placer des points de contrôle au clic droit et confirmer le tracé avec Entrée.
  • Supprimer le dernier point avec Suppr ou effacer le tracé avec Échap.
  • Ajuster la densité d’échantillonnage de 2 à 32 points par bloc.
  • Prévisualiser le placement avant de l’appliquer, avec suivi optionnel du terrain.

Environnement et prérequis

Minecraft 1.21.10, Fabric Loader 0.16.0 ou plus récent, Fabric API et Axiom, avec les permissions TOOL et BUILD_SECTION d’Axiom. L’addon ne fonctionne pas sans Axiom.

Premiers pas

Installez l’environnement Fabric compatible et Axiom, puis utilisez l’outil BTE Rail Path dans la palette d’Axiom. Commencez par un tronçon court pour vérifier la palette, la densité de courbes et le suivi du terrain avant d’allonger un corridor. Le README liste les permissions Axiom TOOL et BUILD_SECTION.

Périmètre, limites et attribution

Cet addon ne fonctionne pas sans Axiom. Les palettes de blocs et les API Minecraft sont sensibles aux versions : utilisez les prérequis de la version téléchargée. Le projet n’est pas une release officielle d’Axiom ou de BuildTheEarth.
