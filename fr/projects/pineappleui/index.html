PineappleUI — project file_□×

Expérimentation de transpileur d’interface

PineappleUI est mon expérimentation de description d’interfaces de bureau avec des layouts type HTML/CSS et de génération de code Java Swing natif. Elle relie un vocabulaire d’interface familier du web à une cible UI de bureau.

La cible documentée actuelle est Swing. La source décrit la prise en charge de composants courants, conteneurs, layout, style et intégration d’événements. La question utile n’est pas de savoir si une page web peut devenir n’importe quelle application, mais quelles parties d’une description d’interface se mappent clairement sur la cible soutenue.

Explorer sur GitHub code source

Ce que fait le projet

  • Décrire une interface dans un fichier .pineui.
  • Générer du code Java Swing depuis la description d’interface soutenue.
  • Utiliser la commande de compilation/exécution documentée pour explorer le résultat.
  • Garder visible le comportement spécifique à la cible au lieu de supposer toute fonctionnalité HTML ou CSS portable.

Environnement et prérequis

Python pour le transpileur et un environnement Java adapté pour compiler ou exécuter le code Swing généré. La cible documentée actuelle est Swing.

Premiers pas

La commande de départ du README est python main.py myui.pineui --compile --run. Commencez par un petit layout et inspectez le Java généré avant d’élargir. C’est un workflow de développement, pas une installation de mod Minecraft : le fichier d’entrée appartient au transpileur.

Périmètre, limites et attribution

JavaFX, Android XML et d’autres frameworks UI sont listés comme cibles futures, pas comme fonctionnalités actuelles revendiquées ici. Traitez l’outil comme expérimental, vérifiez la syntaxe soutenue dans le dépôt et testez le code généré avant de vous y appuyer.
