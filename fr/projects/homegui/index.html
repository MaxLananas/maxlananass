HomeGUI — project file_□×

Mod Minecraft côté client

HomeGUI est mon mod client de gestion des homes Minecraft. Au lieu de saisir répétitivement un nom de home dans le chat, ouvrez une interface, recherchez les destinations disponibles et sélectionnez où vous téléporter.

Le mod lit la réponse du serveur à /homes et présente cette information côté client. Il n’installe pas un nouveau système de téléportation sur le serveur : la différence entre interface pratique et plugin serveur reste essentielle pour décider si l’outil convient à votre setup.

HomeGUI — interface

Ce que fait le projet

  • Ouvrir l’interface avec la touche H par défaut ; modifier le raccourci dans les contrôles Minecraft.
  • Rechercher des noms de homes et marquer des favoris d’un clic droit.
  • Consulter l’historique de téléportation récent et des statistiques d’usage local.
  • Utiliser l’interface en anglais ou en français ; préférences stockées dans config/homegui.json.

Environnement et prérequis

Un serveur Fabric Loader et Fabric API compatibles, plus un serveur utilisant des commandes de homes dont la réponse à /homes peut être analysée. Le mod est côté client ; les permissions du serveur s’appliquent toujours.

Premiers pas

Installez un Fabric Loader et une Fabric API compatibles, puis placez le JAR de HomeGUI dans votre dossier mods. Rejoignez un serveur avec des commandes de homes compatibles avant d’ouvrir l’interface. Le fichier JSON local est généré au premier lancement.

Périmètre, limites et attribution

Les permissions et règles de téléportation du serveur s’appliquent toujours. Un serveur au format de chat fortement personnalisé ou obfusqué peut ne pas être analysé correctement. Vérifiez la page de téléchargement actuelle pour les versions soutenues.
