Plugin tutoriel Paper

TraceBTE est un plugin tutoriel de tracé interactif développé pour BuildTheEarth France. Il aide à introduire la séquence entre trouver un lieu réel et placer son emprise de bâtiment dans Minecraft.

Le tutoriel vit sur le serveur, pas dans un client Fabric. Son sujet est la méthode du builder : récupérer des coordonnées géographiques, rejoindre le lieu correspondant dans le monde projeté, placer des repères d’angle et utiliser WorldEdit pour relier et prolonger la construction.

Explorer sur GitHub code source

Ce que fait le projet

  • Démarrer la séquence guidée avec /tuto et l’interrompre avec /tuto stop.
  • Récupérer des coordonnées GPS et utiliser la commande /tpll du serveur.
  • Placer les angles du bâtiment et tracer les edges de l’emprise avec WorldEdit //line.
  • Introduire les sélections et //stack pour prolonger l’emprise vers le haut.

Environnement et prérequis

Un serveur Paper compatible, Java 21+ et FastAsyncWorldEdit selon les prérequis documentés. Le README ne demande pas de fichier de configuration séparé pour le tutoriel.

Premiers pas

L’installation documentée place le JAR du plugin dans le dossier plugins du serveur Paper, suivi d’un redémarrage. Vérifiez d’abord les versions requises de Java et de FAWE. Le README n’exige pas de fichier de configuration séparé pour le tutoriel.

Périmètre, limites et attribution

C’est un tutoriel, pas un importeur automatique de bâtiments ni une alternative à la configuration d’un serveur BTE. Ses commandes et exemples supposent les outils serveur attendus disponibles. Ce portfolio n’est pas un site de support officiel de BuildTheEarth.
