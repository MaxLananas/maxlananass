TerraPlusMinus (contributions) — project file_□×

Génération de terrain BuildTheEarth

TerraPlusMinus transforme des données géographiques en terrain Minecraft : relief, occupation du sol, bâtiments et routes à l'échelle 1:1.

Je contribue des correctifs et améliorations orientées BuildTheEarth, dont les workflows de projection France.

Explorer sur GitHub code source

Ce que fait le projet

  • Génération de terrain réel à l'échelle 1:1
  • Utilisé par les serveurs BuildTheEarth
  • Contributions centrées sur BTE France

Premiers pas

Plugin serveur ; voir le dépôt pour les datasets et compatibilités.

Périmètre, limites et attribution

Projet upstream ; je suis contributeur, pas auteur unique. Licences des datasets applicables.
